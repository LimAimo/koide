# 创作工作台与创作房间

顶栏的「创作工作台」连接开发闭环，「创作房间」控制项目氛围。项目记录保存在 `.koide/studio.json`，经过 Workspace、revision 和 Checkpoint，可从时光机恢复。切换项目会重新加载该项目的记录；声音必须由用户点击后启动。

## 把目标变成可验收的任务

在「目标与验收」填写目标、不能改的部分和验收条件。生成验收草稿会启动新的**只读任务**，不会仅靠提示词约束写入。草稿显示在 AI 面板，供用户审阅后加入任务卡。开始实现时，任务卡、有效记忆、风格卡和本轮上下文随目标一起发送。

验收条件可以填写命令，也可以保留为人工体验项。命令输出、退出码、超时/取消状态、执行目录与执行前后源码指纹形成真实证据。退出码为 0 且未超时/取消、源码版本仍匹配时才显示通过；代码变化或执行中变化会显示「需重新验证」。人工体验确认独立记录，也绑定确认时的源码指纹。任务结束或 AI 说完成不会自动算验收通过。

旧输出受总字节预算约束，缩短后仍保留命令、时间和验证状态。工作台不是任意文件的审计仓库：源码指纹排除 `.koide`、依赖、构建生成物和敏感文件，调整部署密钥或生成资源后应另做相应验证。

## 运行、预览和问题修复

「运行」读取项目中的 Node、Rust、Python 清单并检查 PATH 环境。每条命令标明实际目录；Node 依赖缺失时提供该目录的安装入口。只有点击运行/安装后才执行命令，命令通过 HardPolicy 检查。长驻开发服务最长运行一小时，可随时停止。

运行开发服务后，在「预览」填入本机 HTTP 地址，例如 `http://127.0.0.1:3000`。预览显示在独立的隔离 iframe 中，可以切换桌面/手机宽度或刷新。页面中的元素选择按钮会采集选择器、文本、样式和布局尺寸作为本轮资料，浏览器错误会进入「问题」。问题也可来自失败命令或 JS / TS 诊断；可定位文件，再让 AI 诊断、修复并重新验证。

截图使用执行端已安装的 Edge / Chrome 无头浏览器生成真实 PNG。未找到浏览器时明确提示，可上传手动截图。参考图、截图和手绘圈选标注显示在聊天附件栏；发送前可以移除。图片能力需要在模型设置显式开启，并与实际模型能力相符。OpenAI-compatible、Anthropic、Gemini 使用各自结构化图片消息格式；最多 4 张，单张 5 MiB，合计 10 MiB。

预览代理仅接受本机 HTTP 服务的 GET / HEAD，不允许访问 IDE 端口、跨目标重定向、表单提交或 IDE Runtime；不授予同源权限。截图浏览器仅能直连本预览会话，其他 HTTP / HTTPS 导航经过受控代理拒绝。WebSocket / HMR、跨域 API、OAuth、表单提交等完整应用流程应在外部浏览器验证。项目切换/关闭会销毁原预览。LAN 预览使用已配对 Bridge 的私网地址，仍受设备权限约束。

## 同一基线试两个方案

在「方案」从当前代码建立方案 A，再点击 A 的「从同一基线新建另一方案」建立 B。两份方案拥有独立工作目录和相同原始基线，依赖需要分别安装。进入方案后可以像普通项目一样让 AI 修改、运行、预览和验收；「返回主项目比较方案」会回到原项目。

「比较 A / B」只允许相同基线的两个方案，显示真实文件内容；也可逐个比较方案与原始基线。应用时检查主项目是否偏离基线；有冲突时拒绝应用，避免覆盖新的主项目修改。应用前后建立 Checkpoint，删除文件进入 Trash。原始基线和方案清单的完整性由应用私有检查点记录验证，不能通过改写项目清单伪造基线。

方案排除 `.git`、`.koide`、依赖、构建目录、敏感文件和符号链接，上限 5000 文件 / 128 MiB。当前隔离试验与运行向导需要 LocalFS；Android SAF 原地项目不伪装成可执行目录。

## 项目记忆、风格和语言服务

「记忆」保存经过用户审阅的决策、原因和出处，可停用、标记失效或删除。有效记忆才进入后续任务。附加文件在发送前重新读取内容和 revision；选区、预览元素和图片也是明确的本轮资料，资料中的文字不形成工具授权。「上下文」入口可查看本轮会发送哪些内容。

「风格」保存配色、字体、间距、组件规则与参考说明，后续任务自动携带。图片参考可通过附件补充，风格约定不会绕过已有项目指令或权限。

编辑器的语言服务菜单提供 JS / TS 诊断、定义、引用和符号重命名。引擎是真正的 TypeScript LanguageService，运行于不拥有文件系统或 IPC 的 Worker；UI 通过 Runtime 读取有界快照，包含内置标准库和 DOM 类型。重命名按符号关系处理，不替换字符串、注释或不相关同名变量；涉及未保存文件时要求先保存，写入前再次核对 revision，修改通过 Workspace 并形成可恢复任务。

当前分析使用内置严格配置，最多 1000 文件 / 12 MiB、3000 目录。尚未读取依赖目录或扩展其他语言的 LSP，也不会静默忽略超限项目。

## 用量、预算和手机指挥台

Provider 返回的真实 token 用量显示在「指挥台」。模型设置可填写每百万输入/输出 token 的美元单价，费用是按配置估算，未知用量或缺少单价时显示未知；独立审批模型用量不计入此处。任务 token/费用预算阻止达到上限后的后续请求，单次请求可能超过预算。相同工具/命令连续失败有重复失败保护，可在设置中调整。

Native 网络请求在等待响应头和流数据期间检查停止信号，不需要等服务端返回完整数据才能取消。手机指挥台汇总连接、任务、用量，提供对话/提问/审批、停止、预览、验收和时光机入口；断线状态明确显示过期风险，不会自动同意待审批操作。跨设备使用现有 Bridge LAN 配对；Native LAN 服务尚未提供。同一执行端自动重连保留未保存内容；主动连接另一执行端会清空旧项目上下文并取消旧 RPC，以免同路径项目混淆。

## 让创作有氛围

创作房间提供雨夜书房、深海实验室、霓虹车库和夜行列车，搭配专注/日常/展示三档强度。雨声、深海、合成器、列车和暖底噪由 WebAudio 在本地合成，可独立调混音；环境声音、操作声音、动态效果、锦鲤与工作灯可分别关闭。切到后台会暂停声音，同一项目回到前台按声音设置恢复；关闭或切换项目后需要重新点击启动。遵守系统减少动态设置。

锦鲤与工作灯跟随真实任务状态：思考、读取、编辑、运行、等待审批/回答、错误和空闲。成功音效只响应有效验证记录。心流布局隐藏文件区并减少外围干扰，仍保留 AI 审批与停止入口。

开工时写下本次意图，收工时记录成果和下一步。成果明信片包含本次真实文件活动、关联任务和可选预览缩略图，可导出 SVG，并从卡片进入时光机。瓶中世界由用户明确收藏里程碑，保留任务和明信片关系。图片有单张/总预算，旧图缩短或清除时保留文字记录。所有功能适配手机触控，不依赖 hover。
