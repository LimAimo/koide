# 桌面与平板操作说明

## 桌面工作区

900px 及以上且以鼠标为主要指针的窗口使用桌面布局。左侧文件、中间编辑器、右侧 AI 为常驻分栏；顶栏左侧放项目工具，右侧放 AI、工作台、创作房间与设置。进入其他项目保留桌面的 AI 显示选择。

拖动分栏线调整宽度，键盘聚焦分栏线后用方向键调整，Home / End 选择允许的最小 / 最大值。窗口变窄时自动限制侧栏，为编辑器至少保留 360px；恢复宽窗口后使用原有偏好。隐藏文件或 AI 不影响另一栏。

终端在编辑器下方，拖动横向分隔线或按上下方向键调整高度。终端跟随容器尺寸变化调整 PTY，隐藏或关闭界面不自动结束运行中的会话。Windows Python Bridge 明确不提供交互式 PTY，浏览器兼容模式会提示并降级；Windows Native Core 提供交互式终端。

设置、创作工作台和创作房间使用中央主区域页面；简短确认仍居中，其他工具以居中面板打开，菜单靠近触发入口。设置可以点击分类或搜索，主区域较窄时分类自动改为横排。按 Esc 关闭最上层并回到入口。

| 快捷键 | 操作 |
|---|---|
| Ctrl / ⌘ + 1 | 显示或隐藏文件 |
| Ctrl / ⌘ + 2 | 显示或隐藏 AI |
| Ctrl / ⌘ + 反引号 | 显示或隐藏终端 |
| Ctrl / ⌘ + 逗号 | 打开设置 |
| 标签页左右方向键、Home / End | 切换打开的文件 |
| 标签页右键或 Shift + F10 | 打开文件操作菜单 |

分屏会根据编辑区的实际宽度自动切换左右或上下排列，不必关闭后重新打开。

单击文件先打开预览标签；双击文件或预览标签会把它保留为普通标签，随后预览其他文件不会替换它。并发打开同一个文件会合并到同一标签，并保留已经输入的内容。

## 平板侧栏

600–899px 的窗口或屏幕短边至少 600px 的触控设备使用平板布局。触控平板即使横屏宽于 900px 也保留侧栏交互；手机横屏和软键盘不会仅因宽高比改变被误判成桌面。

文件入口在左侧，文件侧栏从左边出来；AI 入口在右侧，AI 侧栏从右边出来。设置、Git、时光机等工具根据触发入口所在边展开。关闭侧栏后仍回到原来的文件和滚动位置。

平板侧栏始终作为覆盖层叠在编辑区上方，横屏或更宽屏幕也不会推开内容；编辑区的位置、宽度和分屏布局保持原样。覆盖时显示遮罩并限制背景键盘焦点，关闭后先恢复交互，再返回原来的编辑或入口焦点。打开文件侧栏会收起 AI 侧栏，打开 AI 侧栏会收起文件侧栏。切换横竖屏时仍使用覆盖层；设置表单使用同一组输入节点，正在输入的查询与焦点不会因尺寸变化丢失。

## 手机与动态效果

手机继续使用原有文件抽屉、AI 半屏与自由拖动全屏、完整设置页。所有触控入口保留至少 40px，菜单无需悬停即可操作。系统减少动态效果会关闭适配面板的移动过渡。

真实浏览器回归使用已安装的 Edge 和临时项目，覆盖 1440 / 900 桌面、768 / 1024 触控平板、390 / 320 手机。运行方法见 [浏览器回归说明](../tests/browser/README.md)。手机浏览器和平板模拟回归不代替 Android APK 或实体平板验收。

本轮结果与 Windows 交付检查见 [1.0.0 界面验收](RESPONSIVE_VALIDATION.md)。
