## 本轮实现

| 范围 | 行为 |
|---|---|
| AI Bottom Sheet | 跟手拖拽；最近 100ms 速度采样；停顿后释放清除过期速度；可取消阻尼弹簧；半屏吸附和自由高度；全屏向下 fling 优先回半屏；关闭后重开半屏 |
| 手势边界 | 单个主指针拥有手势；pointercancel / lostpointercapture 恢复原位；旋转、视口变化或隐藏时取消残留动画；把手可用键盘调整 |
| 文件抽屉 | 移除覆盖跟手 transform 的强制样式；纵向滚动不抢手势；浮层内部触摸不会同时触发文件抽屉 |
| Sheet / Dialog / Menu | 关闭立即更新交互；动画帧不能重新打开已关闭面板；返回事件串行处理；嵌套关闭与立即重开保持正确层级；异步确认和菜单选择防重复执行 |
| 工作现场 | 按阶段 ID / 稳定活动 ID 更新原有节点；保留列表和滚动；准备调用替换为正式调用时复用活动身份；去掉重复说明 |
| Tool Card / 发送按钮 | 工具卡状态图标保留节点并淡入淡出；错误展开同步 aria-expanded；沿用已有发送/停止连续图形过渡 |
| Time Machine | 加载、错误、重试及空状态；异步响应过期后不覆盖新任务；按文件显示逐步累计增删；按事件显示行号、修改范围、内联 Diff、区域跳转、调用来源；保留动画重播并清理关闭后的编辑器 |
| 历史真实性 | Native / Bridge 保存 after_blob；旧记录必须匹配 after_rev；删除后重建、外部修改、回滚都不能重写历史展示；Native 无变化写入不新增修改节点 |
| 验证故事 | 同命令、同 cwd 才可关联失败与通过；无修改重试单独说明；通过后再修改或撤销时提示需重新验证；节点可跳回实际事件 |
| 减少动态效果 / 触屏 | 应用内设置同步到普通 UI；系统设置仍受尊重；触屏把手、小按钮、文件行至少 40px；Diffusion 引擎保持独立 |

## 实现边界

- 文件统计是逐步累计，包含撤销记录；不是整任务净差异。
- 超出行比较预算、二进制和无法核对的旧历史明确降级；预览最多渲染 1200 行，统计仅在完整比较成功时提供。
- Runtime API 业务方法数量仍为 72；本轮扩展 checkpoint 元数据和返回字段，不新增传输接口。
- Native haptic、声音反馈和 1.x 功能本轮未接入。保留 Android one-shot shell、Native LAN 尚未实现、同步网络读取停止可能延迟等现有限制。
- 本轮没有更换 UI 风格，也没有重写 Diffusion 动画系统。
