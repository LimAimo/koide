# 自适应页面与弹层

完整功能页和工具面板共享内容节点，设备尺寸变化只移动或重排节点，保留尚未提交的输入。界面初始化时调用 `configureSurfaces({ app, pageHost })`，其中 `pageHost` 是桌面编辑器主区域内的页面容器。

## 展示方式

`openSheet` 保持 `{ close, el, content }` 返回值，额外接受：

- `presentation: "page"`：设置、创作工作台等完整功能页。桌面进入主区域，平板使用定向侧栏。
- `presentation: "panel"`：默认工具面板。桌面居中，平板使用定向侧栏，手机使用底部面板。
- `anchor`：实际触发元素，或带 `element` 和 `getBoundingClientRect()` 的菜单坐标对象。菜单后的确认框会继承来源元素，用于恢复焦点。
- `side: "left" | "right"`：显式指定侧栏方向；省略时优先使用触发元素祖先的 `data-surface-side`，再根据触发位置决定。
- `mobileFullscreen: true`：手机以完整页面展示，不改变平板侧栏和桌面页面语义。

平板侧栏宽度在 320–560px 之间调整，始终使用覆盖层、遮罩和背景焦点隔离，不占用主区域空间。横竖屏与宽屏切换也不会推开编辑区；`data-push` 固定为 `false`，不再提供占位变量。核心布局变化发送 `koide:layout-resize` 后，侧栏更新展示方式，同一组输入节点、焦点与选区得到保留。

`openMenu(title, items, { anchor, side })` 在桌面使用锚定菜单，支持方向键、Home、End、Escape 与 Tab；触控设备遵循侧栏或底部面板规则。`openDialog` 始终居中，并提供背景隔离、键盘焦点循环与来源焦点恢复。

## 关闭与页面切换

`pushLayer` 返回幂等关闭函数，普通用户关闭会返回一层历史；`.dismiss()` 同步移除当前层，不发起历史导航，适用于设备模式切换和明确的页面替换。尚未结束的历史导航期间，新层会在导航落定后登记，避免菜单立即打开确认框时跳出应用。

用户明确打开文件时调用 `dismissPageSurfaces()`，只退出 `presentation: "page"` 功能页；普通工具面板和确认框不受影响。后台智能体定位文件不调用该方法，以保留用户正在填写的设置。设备模式切换和关闭会清除拖动状态与焦点隔离；手机拖动手柄仅用于底部面板。

设置分类导航按自身容器宽度重排：宽度不超过 700px 时横排，其余情况下使用左侧分类栏，避免桌面窄编辑区被固定导航挤压。
